# 指令包记录

指令包独立于软件版本，单独在这里记录，时不时增加。
产出的 zip 统一放在仓库根目录的 `指令包` 文件夹里。

> [!NOTE]
> **统一通知规范**：
> 所有指令包已彻底淘汰各自弹出的 `[MessageBox]::Show` 与 Windows 托盘气泡通知。全部改为由 Pinwheel 软件本体接管并在屏幕右下角以现代 Win11 Fluent Toast 悬浮卡片展示，**显示 3 秒后自动平滑淡出关闭**，支持倒计时条和悬停暂停，绝不争抢前台焦点。

## 现有指令包

### 打开计算器（全局）

- 文件：`指令包/Windows-打开计算器.zip`
- 说明：打开 Windows 计算器，任何软件里都能用。

### Excel 自动列宽列高（EXCEL.EXE）

- 文件：`指令包/Excel-自动列宽列高.zip`
- 说明：选中单元格后执行，调用 Excel/WPS 原生接口自动调整列宽和行高，不模拟按键。

### Excel 1.2倍列宽（EXCEL.EXE）

- 文件：`指令包/Excel-1.2倍列宽.zip`
- 说明：把选中单元格所在列每一列的列宽放大到 1.2 倍，调用 Excel/WPS 原生接口实现，不模拟按键。

### Excel 1.2倍列高（EXCEL.EXE）

- 文件：`指令包/Excel-1.2倍列高.zip`
- 说明：把选中单元格所在行每一行的行高放大到 1.2 倍，调用 Excel/WPS 原生接口实现，不模拟按键。

### Excel 添加边框（EXCEL.EXE）

- 文件：`指令包/Excel-添加边框.zip`
- 说明：给选中的单元格加边框：内部细线、外侧粗线。调用 Excel/WPS 原生接口实现，不模拟按键。

### Word 当前文档转PDF（WINWORD.EXE）

- 文件：`指令包/Word-当前文档转PDF.zip`
- 说明：把 Word 当前打开的文档转成 PDF 保存到桌面。调用 Word/WPS 原生导出接口实现，毫秒级快速导出，不模拟按键。支持 Word 与 WPS。

### Excel 当前文档转PDF（EXCEL.EXE）

- 文件：`指令包/Excel-当前文档转PDF.zip`
- 说明：把 Excel 当前打开的工作簿导出为 PDF，保存到桌面。调用 Excel 原生导出接口，不模拟按键。

### Everything 搜索（全局）

- 文件：`指令包/Everything-搜索.zip`
- 说明：读取“当前选中的文字”（无需手动复制），用 Everything 搜索。需要电脑已安装 Everything。

### 提交到 DeepSeek Harness（全局）

- 文件：`指令包/通用-提交到DeepSeekHarness.zip`
- 说明：读取“当前选中的文字”（无需手动复制），作为任务交给 DeepSeek Harness 在后台执行，完成后右下角提醒并自动打开结果，不弹黑色控制台。任何软件里都能用。需要电脑已全局安装 dsh，或装有 DeepSeek Harness 客户端。

### 录屏（全局）

- 文件：`指令包/通用-录屏.zip`
- 说明：拖过去第一次开始录屏，再拖过去一次停止，并把 MP4 保存到桌面（不录声音）。停止时会正常收尾，保证整段都能播放。优先使用电脑里已有的 ffmpeg，没有时会询问是否通过 winget 自动安装。

- 窗口置顶：`指令包/Windows-窗口置顶.zip`
- 窗口最小化：`指令包/Windows-窗口最小化.zip`
- 窗口最大化：`指令包/Windows-窗口最大化.zip`
- 移到下一屏：`指令包/Windows-移到下一屏.zip`

### 媒体控制（全局，共 4 个）

- 音量加：`指令包/Windows-音量加.zip`
- 音量减：`指令包/Windows-音量减.zip`
- 静音：`指令包/Windows-静音.zip`
- 播放暂停：`指令包/Windows-播放暂停.zip`

### 文档转 PDF（全局）

- 文件：`指令包/通用-文档转PDF.zip`
- 说明：选中 Word / Excel / PowerPoint 文件后执行，批量转成同名 PDF，保存到原文件同目录；同名会自动加时间戳。依赖免费软件 LibreOffice，未安装时会询问是否通过 winget 自动安装。

### 字体文件重命名（全局）

- 文件：`指令包/通用-字体文件重命名.zip`
- 说明：选中 ttf / otf / ttc 字体文件后执行，自动读取字体内部名称，并把文件名改成字体名；文件名非法字符会自动去掉，重名会自动加序号。任何软件里都能用，不模拟按键。

### Illustrator 群组描边 0.1pt（ILLUSTRATOR.EXE）

- 文件：`指令包/Illustrator-群组描边0.1pt.zip`
- 说明：选中群组后执行，按群组的整体外边界画一个 0.1pt 黑色描边、无填充的矩形，只描外框，不处理群组里面的内容。调用 Illustrator 原生接口实现，不模拟按键。

### Illustrator 缩放至选中对象（ILLUSTRATOR.EXE）

- 文件：`指令包/Illustrator-缩放至选中对象.zip`
- 说明：把当前选中的对象缩放到屏幕正中间，并自动调整到适合窗口的大小，类似 CorelDRAW 的 F4。调用 Illustrator 原生接口实现，不模拟按键。

### Illustrator 画板适合选中图稿（ILLUSTRATOR.EXE）

- 文件：`指令包/Illustrator-画板适合选中图稿.zip`
- 说明：把当前画板一键调整到刚好包住选中的图稿，等同 Illustrator 自带的“画板适合所选图稿”。调用 Illustrator 原生接口实现，不模拟按键。

### 划词翻译（全局通用）

- 文件：`指令包/通用-划词翻译.zip`
- 说明：全局划词翻译指令包。选中文本后触发，自动提取内容并在独立单例窗口中流式显示翻译结果。首次使用可配置 API Key（支持 DeepSeek / 硅基流动 / OpenAI / 免密通道），历史记录自动持久保留，支持手动清空与独立关闭。
